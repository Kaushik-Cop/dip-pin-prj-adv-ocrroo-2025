# User Stories

## Story One
As a student who uses a screen reader, I want to enter a time in a coding video and get the code from that frame as text so that my screen reader can read me code the presenter doesn't say out loud.

## Story Two
As a student entering a video time, I want the app to tell me straight away if the time I entered is invalid, so that I don't wait for an OCR request that will fail.

## Story Three
As a student with low vision, I want to change the font size and switch to a high-contrast theme and have those settings saved, so that the extracted text is easier to read every time I use the app.
