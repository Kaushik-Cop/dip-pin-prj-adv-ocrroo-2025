# Persona: Wayne Jack

- **Name**: Wayne Jack
- **Age**: 24
- **Occupation**: First-year Diploma of IT student at TAFE; part-time retail worker
- **Location**: Perth, WA. Studies at home in the evenings
- **Goals**: Learn Python and web development from tutorial videos; get example
  code running on his own laptop so he can experiment with it
- **Frustrations**: Code in tutorial videos is small and often low-contrast.
  Pausing, zooming in and retyping line by line is slow and tiring, and leads to
  errors he then has to debug
- **Motivations**: Wants to move from retail into a junior developer role, and
  enjoys the problem-solving side of programming
- **Technology**: Windows laptop with the built-in screen magnifier set to
  200–300%; high-contrast/dark themes; occasionally uses the NVDA screen reader
  to read long text; prefers keyboard shortcuts over precise mouse work
- **Experience**: Comfortable with everyday computing and assistive settings;
  beginner in Python (loops, functions); still learning to read error messages
- **Personality**: Persistent, practical and self-directed. Prefers to work
  things out alone before asking for help
- **Interests**: Video games, building small automation scripts, and helping
  friends set up their computers

## Context
Wayne has **low vision** (keratoconus), which makes small or low-contrast text
hard to read even when magnified. This is one part of how Wayne works, not who
he is: Wayne is a capable student whose main barrier is that tutorial code is
only available as pixels in a video, not as text.

## Needs
- Code from a paused video available as **real text**, which can be enlarged,
  copied, or read by a screen reader
- **Large, high-contrast display** of the extracted code, adjustable and
  remembered between sessions
- **Keyboard access** to the main actions (pause, extract code, copy) without
  precise mouse targeting
- Clear **feedback** when something happens ("Copied!", errors), which is visible
  *and* announced to a screen reader
